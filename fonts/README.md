# Fonts

Caption, hook and watermark fonts burned into videos. All are licensed under the
SIL Open Font License 1.1 (free for commercial use, including in videos):

- Bebas Neue — Dhiru Kholia / Ryoichi Tsunekawa
- Anton — Vernon Adams
- Archivo Black — Omnibus-Type

`99-clipforge-aliases.conf` maps the names shown in the editor (Impact, Arial Black,
Arial Rounded MT Bold, Arial) to these fonts and Liberation Sans. The Dockerfile
installs both into the system font directory.
