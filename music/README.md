# Background music (optional)

Drop music here only if you're allowed to use it commercially — CC0 / public-domain tracks are safest.
Each track needs a license file next to it with the credit on the first line, or the autopilot
ignores it:

    calm-piano.mp3
    calm-piano.license.txt   ← first line, e.g. "“Calm Piano” by Jane Doe (CC0) — https://…"

No music is better than unlicensed music: a Content ID match can demonetize the video.
